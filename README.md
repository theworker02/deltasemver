# deltasemver

Delta validation gates for semver inputs before they hit prod.

**Site:** https://theworker02.github.io/deltasemver/

## Install / run

```bash
git clone https://github.com/theworker02/deltasemver.git
cd deltasemver
node src/cli.js
node --test
```
